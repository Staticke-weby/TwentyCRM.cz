## 2. Kdo píše česky o Twenty
- **twenty.com/cs** — oficiální web má českou verzi (agenti, MCP server v každém Cloud workspace); #1 na Seznamu pro „Twenty CRM".
- **twentycrm.cz** #2 pro „Twenty CRM"; umisťuje se i pro „open source CRM česky" a „twenty open source CRM" (#5).
- **bohemiacrm.cz** (sesterská značka) se umisťuje na „open source CRM česky", „CRM pro servisní firmy", „CRM na vlastním serveru", „implementace CRM cena" → **riziko kanibalizace, rozdělit témata**.
- Jinak žádné české recenze, návody ani srovnání Twenty (jen subger.com/cs, techsy.io/cs). Přehled open source CRM (https://www.vaclavkeil.cz/nejlepsi-open-source-crm-2025/) Twenty nemá.
- Našeptávač „twenty crm": docker, self hosted, api, review, whatsapp, gdpr, demo — vše anglicky.

## 3. Mezery
1. **Open source a vlastní server česky** — výsledky na Seznamu jsou anglické; nejjasnější mezera.
2. **MCP pro CRM a firemní systémy** — chybí nezávislé srovnání, kdo má MCP (Raynet, Pipedrive, HubSpot, Salesforce, Twenty), jak připojit Claude/ChatGPT, bezpečnost; našeptávač ukazuje i „mcp server pohoda".
3. **Agentní CRM / AI agent v CRM** — tenké, strojově přeložené; chybí praktické české scénáře pro obchod a servis.
4. **Software pro servis v terénu** — „plánování výjezdů techniků" bez reklam a jen malí dodavatelé; jediný český FSM vysvětlovák (https://www.datasys.cz/co-to-je-field-service-management-fsm-a-proc-ho-potrebujete-pokud-vasi-lide-pracuji-v-terenu/).
5. **GDPR + CRM zastaralé** (2018–2020), **AI Act + CRM/agenti** nikdo nespojuje.
6. „Salesforce alternativa" — na Seznamu jen anglická stránka; „CRM zdarma" slabé weby, bez reklam.

## 5. Specifika Seznamu
- Sklik reklamy na komerčních CRM dotazech; na informačních, open source, MCP a „plánování výjezdů" nejsou.
- Seznam dává jedné silné doméně víc odkazů (raynet.cz 7× u „crm systém") → odměňuje hlubokou vnitřní strukturu; kotvy z obsahu stránky se ukazují jako další výsledky.
- Seznam zobrazuje firmy.cz a zbozi.cz → **profil na firmy.cz** je levná cesta do výsledků.
- Česká stránka porazí anglickou, i když je anglická silnější.
